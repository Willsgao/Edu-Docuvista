## 2026-04-06 修复：搜索框无反应 Bug

### 问题
在数据仓库页面输入"建设"搜索建设银行，列表毫无反应。

### 根本原因
三个叠加问题：
1. **核心 Bug**：搜索 API 返回 `res.data = []`（空数组），前端 `searchResults.value = []`
   - `displayBanks` 判断 `searchResults !== null`，空数组满足，显示空列表
   - 原本显示的所有银行全部消失，看起来"没反应"
2. **无防抖**：每输入一个字符就发一次 API 请求，体验差
3. **错误被吞**：`catch(e) { /* ignore */ }` 导致 API 失败时前端完全没有提示

### 修复内容（`BankWarehousePage.vue`）
- `handleSearch` 改为防抖（300ms 延迟），避免频繁请求
- API 失败时降级为**本地过滤**（用已加载的 banks 数组过滤），保证搜索可用
- 搜索无结果时显示 `ElMessage.info` 提示
- 空状态文案区分"无搜索结果"和"无数据"
- 新增 `searchLoading` 状态，搜索时显示加载效果
